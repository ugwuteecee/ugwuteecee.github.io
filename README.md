# Cloud Network Engineer Portfolio

A responsive, minimal portfolio website with a clean editorial style, soft green accents, animated network artwork, and subtle scroll-reveal effects.

## Personalise before publishing

Search `index.html` and replace:
- `YOUR NAME` with your professional name
- `you@example.com` with your preferred email address
- `yourusername` with your GitHub and LinkedIn usernames
- Example project links and descriptions with your real projects, diagrams, repositories, and measured outcomes

Keep project claims accurate: the three case studies are starter examples, not claims that work has already been completed.

## Preview locally

Open `index.html` in a browser. The Google Fonts import requires an internet connection; system fallbacks are included.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `cloud-network-engineer-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published URL shown in the Pages section.

## Included

- Responsive desktop and mobile layout
- Sticky navigation and mobile menu
- CSS network illustration with gentle floating motion
- Scroll-triggered reveal animation using IntersectionObserver
- Reduced-motion accessibility support
- Project cards, skills, and contact section
